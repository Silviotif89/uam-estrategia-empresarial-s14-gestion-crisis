# Gestión y manejo de crisis en la empresa — S14

Presentación guiada para la clase de Estrategia Empresarial. El archivo principal es `index.html`; se abre en el navegador y no necesita instalación.

## Controles

- **← / →**: cambiar diapositiva.
- **N**: mostrar u ocultar la guía docente.
- **F**: activar o salir de pantalla completa.
- El reloj muestra la hora de Managua. El contador de clase dura **160 minutos** y comienza al pulsar **Iniciar clase**; se puede pausar y reiniciar.
- La sesión incluye una pausa sugerida de 10 minutos. Las notas de exposición y las fuentes se consultan desde los botones inferiores.

La presentación contiene 25 diapositivas con definición, tipos e importancia de las crisis, perspectivas filosófica, psicológica y social, casos de Deepwater Horizon y Tylenol, preguntas de discusión y una actividad breve.
